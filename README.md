# 로또
## 구현 기능 목록

### 입력 기능
#### 1. 구입 금액 입력
- 1장당 1000원
#### 2. 당첨 번호 입력
#### 3. 보너스 번호 입력

### 로또 관련 기능
#### 1. 로또 발행 기능
- 중복되지 않는 숫자 6개 뽑기
#### 2. 당첨 계산
#### 3. 수익률 계산
- 소수점 둘째 자리에서 반올림
### 출력 기능
#### 1. 발행한 로또 수량 출력
#### 2. 발행한 로또 번호 출력
   - 번호 오름차순 출력
#### 3. 당첨 내역 출력
#### 4. 수익률 출력

### 예외 처리
#### 1. 구입 금액
  - 숫자가 아닌 경우
  - 1000원 단위가 아닌 경우
#### 2. 당첨 번호
  - 쉼표로 구분되어 있지 않은 경우
  - 구분된 번호가 숫자가 아닌 경우
  - 6개가 아닌 경우
  - 숫자 범위가 1~45가 아닌 경우
  - 당첨 번호가 중복되는 경우
#### 3. 보너스 번호
  - 숫자가 아닌 경우
  - 숫자 범위가 1~45가 아닌 경우
  - 당첨 번호와 중복되는 경우
